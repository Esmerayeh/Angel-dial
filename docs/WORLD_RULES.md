# World Rules

- No navbar.
- No login.
- No normal page cards.
- Rectangles must be cursed popups, fake browsers, terminals, old OS windows, or error objects.
- Every visible object should react to hover/click/drag/pull/tune in some way.
- Wrong clicks are rewarded.
- Darkness must still contain fog, grain, scanlines, distant architecture, or tiny beings.

MVP worlds:

- Angel Dial: central machine
- Cyber Goth Mall: spiral mall, arcade, CD tray micro-world
- Archive Ocean: whirlpool, browser windows, dead forum bottle
- Angel Server Cathedral: halo engine and SERAPH-404
- Forgotten Orrery: constellation machine and secret unlocks
- Memory Hospital: ghost-pull emotional space
- Floor NULL: myth floor, no resolution
