# Performance Budget

Dense, but fast:

- Load the Angel Dial shell first.
- Lazy-load heavy future worlds.
- Use instancing for repeated 3D assets.
- Prefer emissive materials and CSS light illusions over many real-time lights.
- Pause hidden worlds.
- Keep physics bodies rare and meaningful.
- Compress GLBs and textures.
- Respect reduced motion.
- Mute is always available.
- Loading should be diegetic: moths, clock calibration, elevator movement, candle melting.
