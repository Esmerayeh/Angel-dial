# Motion Rules

Every major movement follows four beats:

1. Anticipation: ticks tighten, particles draw inward, creatures freeze.
2. Transformation: rings align, portals bloom, curtains stretch, windows bend.
3. Travel: clock tunnel, ghost veil, elevator shaft, whirlpool, browser wormhole.
4. Arrival: the world assembles and a clue lands near the cursor.

Allowed transition families in the MVP:

- Clock Bloom
- Spiral Descent
- Orrery Shift
- Liquid Glass Warp
- Ghost Veil
- Elevator Climb

No route-change feeling. The world should always seem to physically transform.
